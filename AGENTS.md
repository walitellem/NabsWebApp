# GStack Guidelines & Engineering Principles

This repository follows the **GStack** framework (by Garry Tan), turning the AI coding agent into a full startup engineering team.

## Core Tenets
1. **Adversarial Review & Quality First**: Every feature and code change must be rigorously verified, robustly tested, and built to production standards with zero regressions.
2. **Immaculate UX & Craft**: Meticulous attention to typography, spacing, contrast, neumorphic/modern design, and intuitive user workflows.
3. **End-to-End Reliability**: Full type safety (TypeScript), zero runtime errors, lazy initialization of external services, and robust error handling.
4. **Structured Execution**: Clear planning, incremental validation (`lint_applet`, `compile_applet`), and clean modular code organization.
